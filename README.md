## Как искать

Нажмите `Ctrl+F` (на GitHub — тоже работает) и введите:

| Что нужно | Введите |
|---|---|
| Следующий правильный ответ | `>>>` |
| Начало главы | `ГЛАВА` |
| Вопрос по номеру | `1.42` — глава 1, вопрос 42 |
| Вопросы со словом | `табличная часть` |

Нумерация вопросов — как в официальном сборнике: `глава.номер`.
